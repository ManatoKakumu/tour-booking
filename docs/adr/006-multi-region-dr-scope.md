# ADR-006: マルチリージョンDRの不採用(単一リージョンバックアップ+オフライン業務継続を採用)

## コンテキスト
- 障害発生を考慮した、バックアップ体制やDR計画について考慮する必要がある

## 選択肢
- 単一リージョンバックアップ体制
- 単一リージョンバックアップ体制+オフライン体制
- マルチリージョンバックアップ体制

## 決定
- 単一リージョンバックアップ体制+オフライン体制

## 理由
- マルチリージョンバックアップ体制であれば、プライマリのリージョンで障害が発生しても、フェイルオーバーすることで事業継続ができる。しかし、そのためにはクロスリージョンレプリケーションの設計・実装や、RTOが短いのであれば最低限のリソースを稼働させる、などコストが跳ね上がる。現段階では、利用者がほぼ0であることから、リージョン障害で事業停止してもインパクトが小さく、DR計画を実装することによるコストには見合わないと判断した。仮にDR計画を実装する際にも、新リージョン側の構築は別途必要になるが、既存(プライマリ)リージョン側はレプリケーションルールの追加程度で済み、大幅な変更は不要な点も、この決定の一因である
- 単一リージョンバックアップ体制だけだと、リージョン障害の際に、一切の事業が行えなくなる。そのため、電話を用いたオフライン体制で運用できるようにする。そのためには、メールに自社やツアー提供会社の電話番号を記載する。会員登録完了メールには自社の電話番号、予約完了メールには自社およびツアー提供会社の電話番号を記載する
